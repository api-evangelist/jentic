Jentic launched a free CLI and web UI tool that evaluates whether APIs are ready for use by AI agents, scoring them across six readiness dimensions. The CLI integrates into developer workflows to generate fresh scores automatically with each code update. CEO Sean Blanchfield stated: "In the AI era, the API is king, and APIs must be built for agents, not just for developers."
